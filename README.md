## B2B: Для логистов

### 2. Автоматизация документооборота

**Что:** заявки, договоры, ТТН, УПД, акты — шаблоны, автозаполнение, подпись, отправка, архив. Сейчас всё в мессенджерах и на бумаге.

| Критерий | Оценка |
|---|---|
| Сложность вайбкода | 🔴 Высокая |
| Спрос | 🔥🔥🔥 Высокий |
| Конкуренция | 🟡 Средняя |
| Кто платит | Компания |
| Чек | 3–20 тыс. ₽/мес |
| Цикл сделки | 2 недели – 2 месяца |

**Почему сложно:**
- **ЭЦП и юрзначимость** — без ЭДО (Диадок, СБИС, Такском) документ не имеет силы. Нужны API, сертификаты, ФНС.
- **Регуляторика** — форматы ТТН, УПД, ЭТрН меняются, надо следить.
- **Интеграции** — 1С, бухгалтерия, склад. Без них не купят.
- **Хранение и аудит** — бэкапы, логи, срок хранения 5 лет.
- **Ответственность** — если документ не дошёл или подпись невалидна, клиент теряет деньги и судится.

**Каналы продвижения:**
- Прямые продажи логистам и автопаркам
- ATI.SU, Della — форумы и партнёрства
- Выставка TransRussia
- Через бухгалтеров и юристов в нише
- Интеграция с 1С через франчайзи

**Вердикт:** ❌ Не для быстрого MVP. Можно сделать «обёртку» (шаблоны + PDF + отправка без ЭЦП), но это половинчатое решение. Полноценный продукт — стартап на год+ с юристом и интеграциями.

### 5. Расчёт себестоимости рейса

**Что:** калькулятор топлива, платных дорог, амортизации, зарплаты, налогов, простоев. Сейчас считают в голове или в кривых Excel.

| Критерий | Оценка |
|---|---|
| Сложность вайбкода | 🟢 Низкая |
| Спрос | 🔥🔥 Средний |
| Конкуренция | 🟢 Низкая |
| Кто платит | ИП, микрологист |
| Чек | 300–1500 ₽/мес |
| Цикл сделки | Короткий |

**Почему просто:**
- Чистая математика + UI. Нет регуляторики, интеграций, ответственности.
- MVP за выходные: форма → расчёт → шаблоны → экспорт PDF/Excel.
- AI можно прикрутить для подсказок («расход выше среднего по маршруту»).

**Почему спрос средний:**
- Многие считают «в голове» и не хотят заморачиваться.
- Кто считает серьёзно — уже в Excel и не хочет менять.
- Реальная боль — у микрологистов и ИП, но их немного.

**Каналы продвижения:**
- Telegram-чаты ИП-водителей и микрологистов
- YouTube-блогеры про дальнобой
- ATI.SU форум
- Как бесплатный лид-магнит для дорогого продукта (CRM, контроль рейса)

**Вердикт:** ✅ Идеально для вайбкода как первый продукт или лид-магнит. Как самостоятельный бизнес — чек маленький, потолок низкий. Использовать как вход в аудиторию.

### 6. Контроль рейса в реальном времени

**Что:** панель, где логист видит все машины, статусы (погрузка, в пути, выгрузка, простой), отклонения от маршрута, GPS.

| Критерий | Оценка |
|---|---|
| Сложность вайбкода | 🟡 Средняя |
| Спрос | 🔥🔥🔥 Высокий |
| Конкуренция | 🟡 Средняя |
| Кто платит | Компания |
| Чек | 500–3000 ₽/машина/мес |
| Цикл сделки | Средний |

**Почему средняя сложность:**
- **GPS-данные** — откуда брать:
  - интеграция с GPS-операторами (АвтоГРАФ, Galileosky, Wialon) — API платные и разные;
  - мобилка водителя с геолокацией — проще, но водитель должен держать включённой;
  - телематика производителя — сложно.
- **Статусы рейса** — водитель отмечает вручную (просто, но нужна дисциплина) или автоматически по геозонам (сложнее).
- **Real-time** — WebSocket, push, карта. Для вайбкода норм.
- **Мобилка для водителя** — обязательна, иначе данных нет.

**Почему спрос высокий:**
- Логист с 10–20 машинами страдает от «где машина, что с ней».
- Простои и срывы сроков = деньги. Готовы платить.
- Wialon, 1С:TMS — тяжёлые и дорогие для микробизнеса.

**Каналы продвижения:**
- Прямые продажи микрологистам и автопаркам (10–50 машин)
- ATI.SU, Della
- Выставки (TransRussia)
- Партнёрство с GPS-операторами (они — телематика, ты — софт)
- Telegram-чаты логистов

**Вердикт:** ✅ Хороший баланс сложности и спроса. Нужна мобилка водителя + GPS-интеграция. Не «за выходные», но MVP за 1–2 месяца реально.

## B2C: Для водителей

### 2. Учёт топлива и расходов

**Что:** заправки, чеки, расход, ремонт, доход за рейс, чистая прибыль. Сейчас — блокнот или Excel.

| Критерий | Оценка |
|---|---|
| Сложность вайбкода | 🟢 Низкая |
| Спрос | 🔥🔥🔥 Высокий |
| Конкуренция | 🟡 Средняя (Fuelio, Drivvo — западные) |
| Кто платит | ИП-водитель |
| Чек | 200–500 ₽/мес или 1500–3000 ₽ разово |
| Частота | Ежедневно |

**Почему просто:**
- Чистая математика + локальная БД (SQLite) + простой UI.
- Нет регуляторики, интеграций, ответственности.
- Офлайн-режим обязателен — решаемо (локальная БД + синк при связи).
- MVP за 1–2 недели: заправка → расход → отчёт.

**Почему спрос высокий:**
- Трата на топливо — ежедневная боль.
- ИП должен считать рентабельность рейса, иначе работает в убыток.
- Западные приложения не учитывают РФ-специфику: платные дороги, тахограф, налоги ИП, ГСМ-нормы.
- Многие до сих пор в блокноте/Excel — рынок «переучить».

**Что важно:**
- **Ввод за 10 секунд** — иначе забросят.
- **OCR чеков через камеру** — killer feature.
- **Офлайн-режим** — в рейсе связи нет.
- **Отчёты для налоговой** — плюс для ИП.
- **Синк с женой/бухгалтером** — часто считает кто-то другой.

**Каналы продвижения:**
- Telegram-чаты водителей и ИП (по регионам, направлениям)
- YouTube/TikTok блогеры-дальнобойщики
- ATI.SU, Della
- Стоянки, заправки, автосервисы — QR-наклейки
- Рефералка «приведи коллегу — месяц бесплатно»
- Avito

**Монетизация:**
- Freemium: базовый учёт бесплатно, отчёты/экспорт/несколько машин — платно
- Подписка 200–500 ₽/мес
- Разовая покупка 1500–3000 ₽ (водители не любят подписки)
- Партнёрка с заправками (кешбэк)

**Риски:**
- Низкий чек — нужны тысячи пользователей.
- Высокий отток — бросают учёт через 2–3 недели.
- Скупость — привыкли к бесплатному.
- Конкуренция — бесплатные Excel-шаблоны и западные приложения.

**Вердикт:** ✅ Идеально для вайбкода как первый продукт. Быстро, дёшево, понятно. Потолок средний. Использовать как вход в аудиторию и кросс-продавать (контроль рейса, документы).

### 3. Документы и права в одном месте

**Что:** права, СТС, ПТС, страховка, техосмотр, тахограф, медосмотр, диагностическая карта + напоминания о сроках.

| Критерий | Оценка |
|---|---|
| Сложность вайбкода | 🟢 Низкая |
| Спрос | 🔥🔥 Средний |
| Конкуренция | 🟡 Средняя (Госуслуги) |
| Кто платит | Автопарк (B2B) / ИП (B2C) |
| Чек | 200–500 ₽/мес (B2C), 100–300 ₽/водитель (B2B) |
| Частота | Раз в месяц |

**Почему просто:**
- По сути БД + напоминания + камера.
- Нет сложной математики, интеграций (если не лезть в Госуслуги).
- MVP за неделю: фото → распознавание даты → напоминание.
- AI/OCR для распознавания сроков на фото.

**Почему спрос средний:**
- Проблема есть, но не горит — вспоминают, когда заканчивается.
- Низкая частота: открывают раз в месяц, платят за год. Плохая юнит-экономика.
- Многие решают в Госуслугах, календаре, голове, бардачке.
- Наёмным водителям не нужно — следит автопарк.
- Реальная боль — у ИП и мелких автопарков, но их меньше.

**Что важно:**
- **Автораспознавание** — сфоткал → дата → напоминание. Без ручного ввода.
- **Семейный доступ** — жена/бухгалтер видит сроки.
- **Напоминания в Telegram/WhatsApp** — не только push.
- **Показывать последствия** просрочки — мотивирует.
- **Интеграция с Госуслугами** — killer feature, но API ограничено.

**Каналы продвижения:**
- **Автопарки и логисты** 🔥 — реальные деньги, следят за 10–100 водителей. B2B, чек выше.
- Telegram-чаты ИП-водителей
- YouTube-блогеры («как не попасть на штраф»)
- Автошколы, СТО, страховые агенты — партнёрства
- Тахограф-сервисы

**Монетизация:**
- B2C: подписка 200–500 ₽/мес, конверсия низкая
- B2B: 100–300 ₽/водитель/мес — вот где деньги
- Партнёрка со страховыми, техосмотром, тахограф-сервисами

**Риски:**
- Низкая вовлечённость — отписки.
- Забывают платить — нужна годовая подписка или автоплатёж.
- Госуслуги могут закрыть нишу.
- B2C монетизируется плохо — не платят за «спокойствие».

**Вердикт:** ⚠️ Средне для вайбкода. Технически просто, но B2C юнит-экономика слабая. Идти в B2B (автопарки, логисты). Или объединить с учётом расходов для повышения частоты использования.

## 🎯 Итоговый вердикт

### Топ для вайбкода

1. **Учёт топлива и расходов** — B2C, ежедневное использование, простая монетизация, есть куда расти.
2. **Контроль рейса** — B2B, высокий чек, средняя сложность, MVP за 1–2 месяца.
3. **Расчёт себестоимости** — как бесплатный лид-магнит, не как бизнес.

### Не для вайбкода на старте

- **Документооборот** — регуляторика, ЭЦП, интеграции, ответственность. Нужна команда с юристом.
- **Документы и права** — только B2B (автопарки), B2C не окупится.

### Оптимальная стратегия

1. Запустить **учёт топлива** бесплатно/дёшево → собрать базу водителей.
2. Добавить **документы и напоминания** как фичу → повысить удержание.
3. Продавать **автопаркам** пакет «учёт + документы + контроль» за 500–1500 ₽/водитель.
4. **Документооборот** — только если пойдёт и будут деньги на разработку с юристом.
